# Подготовка к хакатону «Код региона»

Справочная выжимка из присланного PDF «Код региона — призовой фонд» помогает выбрать основу, но не заменяет задание, которое выдадут организаторы. DOCX «Приложение письмо РСО» содержит пустую таблицу для регистрации участников: ФИО, ИНН, телефон и данные сопровождающего. Технического задания в нём нет. Исходные документы в репозиторий не включены.

## Формат

- 11–12 ноября 2026 года, Донецк, Дом молодёжи, проспект Богдана Хмельницкого, 67В.
- Команды формируются на площадке; задания и небольшие наборы данных готовят организаторы.
- Формат команда выбирает сама: сайт, мобильное приложение, адаптивный сервис или другой прототип. React Native не является обязательным требованием.
- Для демонстрации достаточно одного законченного пользовательского сценария. Презентация должна объяснять задачу, пользователей, функции, ограничения и вклад участников.

## Два направления

**Город после пар:** подбор досуга по интересам, времени и бюджету. Минимальный сценарий: запрос → варианты → карточка места или события → передача плана друзьям.

**Старт в профессии:** поиск работы, подработки и сезонной занятости. Минимальный сценарий: навыки и доступное время → предложения → условия вакансии → отклик. В карточке нужны обязанности, требования и график.

В заготовке ни одно направление не выбрано. Демонстрационные карточки показывают только технические возможности основы.

## Оценка

| Критерий | Баллы |
| --- | ---: |
| Соответствие задаче | 20 |
| Работа прототипа | 25 |
| Техническое решение | 15 |
| Практическая польза | 15 |
| Защита проекта | 15 |
| Идея интеграции ИИ | 10 |

Работающая функция ИИ по документу необязательна: оценивается конкретная, полезная и реалистичная идея её применения. На защиту предусмотрено 5 минут демонстрации и 3 минуты вопросов, затем 1 минута на смену команды.

## Практический план

1. После выдачи задания выберите направление и один сценарий до результата.
2. Разделите экраны, данные, сервер при необходимости и подготовку показа.
3. Сначала добейтесь работы полного сценария на небольшом наборе данных.
4. Проверьте пустые результаты, неправильный ввод, недоступность сервера и перезапуск.
5. Подготовьте короткий показ, вклад каждого участника и объяснение готовых компонентов, включая эту подготовленную основу.
